# Сервер обработки ClipForge

Мобильный клиент отправляет видео или идентификатор Twitch VOD в API. Сервер создаёт задачу и возвращает варианты нарезок после обработки.

## Контракт MVP

`POST /api/projects`

```json
{"source":{"type":"upload|twitch_vod","url":"https://..."},"layout":{"faceTopRatio":0.4,"faceTracking":true},"language":"ru","clipDuration":{"min":20,"max":45}}
```

Ответ: `202 {"projectId":"...","status":"queued"}`.

`GET /api/projects/:id` возвращает ход обработки и найденные клипы.

`POST /api/clips/:id/export` запускает рендер `1080x1920 MP4`.

## Конвейер

1. Twitch OAuth подтверждает доступ к VOD владельца, либо файл принимается через подписанный URL.
2. Очередь задач выделяет звук и кадры; ASR создаёт расшифровку.
3. Детектор и трекер лица выбирают говорящего/стримера. Если устойчивого лица нет, используется весь кадр без верхней панели.
4. Ранжировщик сочетает пики громкости, эмоций, активность чата (при доступном Twitch EventSub) и текст речи.
5. FFmpeg собирает верхнюю область 40% с face crop и нижнюю область 60% с игровым кадром, накладывает субтитры и экспортирует MP4.

Все ключи Twitch и URL для загрузки должны оставаться на сервере. Обрабатывайте только видео пользователя или источники с правом на монтаж.
