# ClipForge

Мобильный PWA-прототип для поиска и монтажа вертикальных нарезок из Twitch VOD и загруженных видео. Макет строит клипы с лицом стримера в верхних 40% кадра и игровым видео в нижних 60%.

## Запуск

Откройте `app/index.html` в браузере или раздайте папку `app` любым статическим HTTP-сервером. На телефоне в браузере выберите «Добавить на главный экран» — приложение откроется как отдельное.

Интеграционный контракт и серверный конвейер описаны в `app/server/README.md`.
