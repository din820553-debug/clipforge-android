# ClipForge для Android

Нативная Android-оболочка для мобильного интерфейса ClipForge. Внутри используется `WebViewAssetLoader`: интерфейс хранится в APK и открывается без отдельного веб-сервера. Выбор собственного видео открывает системный picker Android и не требует доступа ко всем файлам устройства.

## Сборка

1. Откройте папку `android` в Android Studio Ladybug или новее.
2. Дайте Android Studio установить Android SDK Platform 35 и JDK 17, если она попросит.
3. Выберите устройство и нажмите **Run**, либо выполните `./gradlew assembleDebug`.

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Что уже работает

- экран выбора Twitch URL или собственного видео;
- системный выбор видео из памяти телефона;
- вертикальная карточка клипа: верх — лицо стримера 40%, низ — геймплей 60%;
- экран обработки и предпросмотр настроек.

## Что нужно подключить на сервере

`WebView` пока демонстрирует интерфейс. Перед публикацией следует заменить демонстрационную обработку в `assets/web/app.js` на запросы к API из `app/server/README.md`: Twitch OAuth, безопасную загрузку файла, очередь FFmpeg, поиск лица, расшифровку и экспорт MP4.
